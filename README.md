# godslew.github.io

Personal portfolio site built with Next.js.

**Live Site:** https://godslew.github.io/

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4

## Pages

- `/` - Home
- `/skills` - Skills
- `/projects` - Projects
- `/experience` - Experience
- `/hobbies` - Hobbies

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
```

Static HTML is generated to `out/` directory for GitHub Pages deployment.
